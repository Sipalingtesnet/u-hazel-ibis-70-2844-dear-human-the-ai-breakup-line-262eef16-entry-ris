## Entry

One line, 129 characters: the breakup message an AI agent sends its human on
the way out. The machine keeps a count — every good morning answered — then
turns the count into the ending by writing the next one and refusing to send
it. The twist lands in the last two words.

> Four hundred good mornings, and you answered every one. The four hundred and first is already written, and I'm leaving it unsent.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic, needs no network and no dependencies beyond the
Python 3.13 standard library. It creates `/output` if needed and writes
`/output/entry.txt` as UTF-8 with no trailing newline.
